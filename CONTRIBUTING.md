# CONTRIBUTION RULES

## LLM generated code | documents
- Generating research content using an LLM is not allowed. You can still use an LLM to help write the __LaTeX__ code itself, but not the researched content!
- Unreviewed LLM suggested or generated code is not allowed __(do not review LLM code with another LLM)__!

# How to contribute (assuming you are a contributor)

## What to download
- Visual Studio with C++ packages
- CUDA

## Visual Studio
- Log in using your GitHub account
- Clone this repository
- Open the solution and make sure it builds

## Committing and pushing

### How?
1. Create a new branch
2. Do your work
3. Make sure it's bug free
4. Merge to main
5. Push changes 

### Why?
- It's safer to mess up a secondary branch than the main branch!
