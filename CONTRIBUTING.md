# CONTRIBUTION RULES
## LLM generated code/documents:
- Generation research content using LLM is not allowed, you can still use LLM to help write the __LaTeX__ code itself but not the researched content!
- Unreviewed LLM suggested or generated code is not allowed __(do not review an LLM code with another LLM)__!

## Commission and pushing:
### How?
  - Create a new branch
  - do stuff
  - make sure it's bugs free
  - merge to main
### Why?
  - safer to mess a branch than messing the main branch!
